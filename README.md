# APQC 流程管理成熟度自评平台

基于 APQC 新版流程管理成熟度模型（七大原则 × 27 个子类别 × 五级成熟度）的在线自评工具。

- **模型架构与逻辑**：五级阶梯、七原则内在逻辑、各原则核心判别维度、演进主线
- **分项打分**：逐个子类别对照五级描述选定"现状"与"目标"，记录评估依据
- **诊断报告**：综合得分与整体阶段、雷达图、子类别剖面、跨原则关联诊断、进阶路径
- **数据**：打分自动保存在本机浏览器；可导出 / 导入 JSON 存档

## 使用

直接打开 `index.html`，或访问 GitHub Pages 发布地址。

## 说明

- 七大原则、子类别定义、五级描述与最佳实践，整理自 APQC 新版流程管理成熟度模型的中文解读资料。
- 子类别 × 等级的分级描述由原则级定义拆解而来；原文未覆盖的格子标注为"推演"。
- 原则等级与整体阶段的汇总规则（均值 + 短板约束）为本平台的自评计算方法，并非 APQC 官方计分公式。
